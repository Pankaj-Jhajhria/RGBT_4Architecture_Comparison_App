# Capturing real screenshots

The README's gallery currently uses illustrative diagrams. To add genuine screenshots:

1. Start the app locally (`python -m streamlit run app.py`) or open the live app.
2. Upload a real MFNet four-channel PNG (and, optionally, its label PNG) and click **Run all four models**.
3. Take browser screenshots of: the input section with thermal preview, a model result panel, and the cross-model summary.
4. Save them as PNG files in `docs/assets/screenshots/` (for example `input.png`, `results.png`, `summary.png`).
5. Reference them from the README's **Live Demo** section with descriptive alt text.

Only publish screenshots of data you are allowed to share, and keep the "illustrative" label on any diagram that is not a real capture.
